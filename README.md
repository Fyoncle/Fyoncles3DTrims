# Fyoncle's 3D Smithing Templates

![Banner](https://cdn.modrinth.com/data/cached_images/6d12b2b7c6b79343387b0fd81336eeb990a86c5e_0.webp)

This resource pack adds 3D Armor Trim Smithing Templates to the game that look beautiful with glowing outlines, while staying compatible with Hold My Items and Shaders.

## ⚙️ Requirements ⚙️

**Versions 1.20.1 and 1.21 & 1.21.1:**  
Requires [Pommel - Held Item Models](https://modrinth.com/mod/pommel-held-item-models)

▔  
**Versions 1.21.4+:**  
No mods required

▔  
**Shader Support:**  
Enable `labPBR` in your shader settings for outlines to actually glow

## ✅ Compatible Mods ✅

[More Armor Trims](https://modrinth.com/mod/more-armor-trims)  
[Frostiful](https://modrinth.com/mod/frostiful)

[Enderscape](https://modrinth.com/mod/enderscape)
